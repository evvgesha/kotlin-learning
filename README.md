# Kotlin Learning

Учебный Kotlin/JVM-проект для IntelliJ IDEA.

## Окружение

- JDK 21
- Kotlin/JVM
- Gradle Wrapper

## Запуск

Откройте проект в IntelliJ IDEA и запустите `src/main/kotlin/lessons/lesson10/homeworks/Maps.kt`,
либо выполните:

```bash
./gradlew run
```

Проверка тестов:

```bash
./gradlew test
```
